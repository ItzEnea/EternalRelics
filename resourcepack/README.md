# EternalRelics Resource Pack

**Professional dark fantasy texture pack for legendary items in Minecraft Paper 1.21.11**

## Quick Start

1. Extract `EternalRelics-ResourcePack.zip`
2. Place in your resourcepacks folder
3. Enable in game settings

## Features

- Custom item textures with emissive layers
- Animated effects (spinning, pulsing, rotating)
- Dark fantasy visual theme
- Faction-specific colors
- Custom sounds (ability, crafting, ambient)
- GUI textures for recipe system
- Particle effects

## Visual Themes

### ☀️ SUN (Human Faction)
Bright golds, whites, and silvers with solar rays and celestial marks

### 💀 CULT (Void Servants)
Crimson reds, dark purples, and eldritch corruption patterns

### ⚫ VOID (Void Entities)
Deep blacks, cyans, and purple void vortex effects

## Installation

### Windows
```
C:\Users\[Username]\AppData\Roaming\.minecraft\resourcepacks\
```

### macOS
```
~/Library/Application Support/minecraft/resourcepacks/
```

### Linux
```
~/.minecraft/resourcepacks/
```
