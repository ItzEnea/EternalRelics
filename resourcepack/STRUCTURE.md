## How to Create the ZIP

1. **Create directory structure:**
   ```bash
   mkdir -p EternalRelics-ResourcePack/assets/minecraft/{textures/{item/{armor,weapons,fragments,relic},gui/{altar,recipes,faction},effect/particles},models/item/{armor,weapons,fragments,relic},sounds/{ambient,ability,craft}}
   ```

2. **Add texture files** (16x16 PNG images) to appropriate directories

3. **Add model files** (JSON files) to models directory

4. **Add sound files** (OGG format) to sounds directory

5. **Create pack.mcmeta:**
   ```json
   {
     "pack": {
       "pack_format": 48,
       "description": "§6§lEternalRelics\n§7Legendary Items & Factions"
     }
   }
   ```

6. **Add pack.png** (64x64 image)

7. **Create ZIP file:**
   ```bash
   zip -r EternalRelics-ResourcePack.zip EternalRelics-ResourcePack/
   ```

## Installation for Players

1. Download `EternalRelics-ResourcePack.zip`
2. Open Minecraft launcher
3. Go to Installations → Resource Packs
4. Click "Open Resource Pack Folder"
5. Extract ZIP into that folder
6. Select resource pack in game
7. Move to "Selected" list

## Texture Format Guidelines

### PNG Specifications
- **Resolution**: 16x16 base (textures)
- **Format**: PNG with transparency
- **Color Mode**: RGBA
- **GUI Textures**: 256x256
- **Pack Icon**: 64x64

### Animated Textures (.png.mcmeta)
```json
{
  "animation": {
    "interpolate": true,
    "frametime": 2,
    "frames": [0, 1, 2, 3, 4, 5, 4, 3, 2, 1]
  }
}
```

## Emissive Texture Naming
- Base: `item_name.png`
- Emissive: `item_name_emissive.png`
- Both added as layer0 and layer1 in item model JSON

## Sound Format
- **Format**: OGG Vorbis
- **Sample Rate**: 44.1 kHz
- **Bitrate**: 128-192 kbps

## Model JSON Template

```json
{
  "parent": "item/handheld",
  "textures": {
    "layer0": "item/weapons/weapon_name",
    "layer1": "item/weapons/weapon_name_emissive"
  },
  "display": {
    "thirdperson_righthand": {
      "rotation": [75, 45, 0],
      "translation": [0, 2.5, 0],
      "scale": [0.85, 0.85, 0.85]
    },
    "firstperson_righthand": {
      "rotation": [0, 45, 0],
      "scale": [0.68, 0.68, 0.68]
    }
  }
}
```

## Compatibility
- Minecraft 1.21.1+
- Paper 1.21.1+
- Works with all shaders (Complementary, BSL, etc.)
- Compatible with most texture pack mods
